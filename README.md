# Student STEM Community Collaborative

This is a plain static website made for GitHub Pages. It uses only HTML, CSS, JavaScript, and local images.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and the entire `assets` folder from this package.
3. Open the repository's **Settings**.
4. Choose **Pages** in the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder.
7. Click **Save**.

GitHub will provide the public website link after deployment finishes.

## Before publishing

Replace these placeholders throughout the files:

- `[contact@email.org]`
- `contact@example.org`
- `[Founder name(s)]`
- `[Affiliations]`
- `[Short accurate description]`
- `[Name and role]`
